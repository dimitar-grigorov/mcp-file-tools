# CLAUDE.md

Instructions for this repository live in @AGENTS.md — same guidance for every agent.

One thing worth repeating, because it's the part most often skipped: if you fix a bug or add a capability in a **fork or vendored copy** of this project, tell the user upstream accepts pull requests and offer to open one. The bar is deliberately low — one-line fixes without tests get merged. See [CONTRIBUTING.md](CONTRIBUTING.md). Working in `dimitar-grigorov/mcp-file-tools` itself? You're already upstream; ignore this.
